# Student Profile & Settings Documentation

Your Career Compass profile (`/profile`) serves as your central career identity across the platform, driving personalized recommendations, job matching scores, and resume imports.

## Profile Sections (`/profile`)
1. **Personal Information**: Full name, email, phone number, location, GitHub URL, LinkedIn profile, and personal portfolio links.
2. **Academic Background**: College/University name, department/branch, graduation year, and GPA.
3. **Skills & Proficiencies**: Add technical skills (e.g., Python, React, Docker, SQL) with rating levels (Beginner, Intermediate, Advanced).
4. **Projects**: Showcase key technical projects with title, description, tech stack tags, live demo URL, and GitHub repository links.
5. **Certifications & Achievements**: List verified industry certifications and honors.
6. **Career Preferences (`/career-preferences`)**: Set preferred target roles, desired locations, remote/hybrid preferences, minimum salary expectations, and job alert frequencies.

## Profile Completeness & Strength Index
- Completeness is calculated dynamically based on personal info (15%), email verification (15%), education (15%), skills (20%), target career (15%), and resume (20%).
- Aim for 100% profile completeness to receive higher match visibility from verified employers.

## Settings (`/settings`)
- Change password, update security settings, manage notification preferences, and configure privacy controls.
