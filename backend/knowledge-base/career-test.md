# Career Test & Assessment Documentation

Career Test (`/assessment`) is Career Compass's multi-step career assessment powered by machine learning algorithms that predict optimal career paths based on individual capabilities and preferences.

## Assessment Steps
1. **Academic Background**: Academic branch, current GPA/percentage, graduation year, and preferred department.
2. **Technical & Core Skills**: Self-rating across programming languages, databases, cloud, and core engineering concepts.
3. **Work & Learning Style**: Problem-solving approach, preferred team dynamics, interest in research vs product development vs operations.
4. **Career Interests**: Preferred industries (Fintech, Healthcare, AI, E-commerce, Aerospace, etc.) and work environments.

## Results & Recommendations (`/results`)
- Predicts top 3–5 matched career roles with confidence match percentages (e.g., 94% Full Stack Developer, 88% Cloud Architect).
- Displays salary outlooks, market demand, key required skills, and learning curves.
- Allows students to select a target career and generate an instant, personalized **Roadmap**.
