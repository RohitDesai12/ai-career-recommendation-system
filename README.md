# AI Career Recommendation System

An AI-powered career recommendation platform that helps students discover suitable career paths, identify skill gaps, analyze resumes, prepare for interviews, and get personalized guidance through an AI mentor.

## Features

- Career Recommendation
- Skill Gap Analysis
- Resume Analysis
- Interview Preparation
- AI Career Mentor
- Personalized Learning Roadmap

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- FastAPI

### Machine Learning
- Python
- Scikit-learn
- Pandas
- NumPy

### Database
- PostgreSQL / MongoDB

### AI
